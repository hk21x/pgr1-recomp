A bug-fix release of the unofficial native PC port of Project Gotham Racing (original Xbox, PAL).

**No game files are included.** You need your own copy of the game. New here? Download **PGR1Launcher.exe** below and
follow the [README](https://github.com/hk21x/pgr1-recomp#readme). Already playing? Press **Update** in the launcher,
then **Play**: your saves, settings and achievements are kept.

## Fixed

- **Music Manager crash.** Opening Options > Music Manager closed the game. A function the screen uses had not been
  recompiled. The Music Manager now opens and builds the Gotham Virtual CD as on the console.
- **Frozen screen at car select.** After the update following 1.0, the picture could freeze at car select in any mode
  and then flicker, while the game carried on underneath (the race could be started by sound alone). The port read
  display settings this game's Xbox libraries do not have. The car select screen and races display again.

## Also in this release

- A draw that would read vertices from outside the game's memory is skipped instead of crashing (a safeguard found in
  the PGR2 port).
- The recorded models the game draws with push buffers are now replayed by the port, as the console does.
- New diagnostics for problem reports: `XBE_DSOUND_LOG=2` lists every sound stream and its volume, `PGR1_DEBUG_LOG=1`
  puts the game's own debug messages in the log (see [WINDOWS.md](https://github.com/hk21x/pgr1-recomp/blob/main/WINDOWS.md)).

Known: the game's sound effects (reverb, filters) are not modelled; system link and split screen have not been
tested; the PAL release is the only one checked.
Please report problems with `PGR1\play\logs\pgr1.log` (the game) or `PGR1\launcher.log` (building).
