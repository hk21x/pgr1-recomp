An update to the unofficial native PC port of Project Gotham Racing (original Xbox).

**No game files are included.** You need your own copy of the game. New here? Download **PGR1Launcher.exe** below and
follow the [README](https://github.com/hk21x/pgr1-recomp#readme). Already playing? The launcher offers this version when
it starts (**Update the launcher**), then to build it; your saves, settings and achievements are kept.

## New

- **More discs supported.** The port now builds from three releases of the game, and the launcher recognises each:

  | Release | Disc image SHA-1 |
  | --- | --- |
  | Europe 1.1 (supported until now) | `4608350bc01c9544da8bd46860ecdfb16cc2d6eb` |
  | Europe and Australia 1.0 | `28bbf6c115f096eeb5785752e1bee34dc2cd7764` |
  | USA 1.0 | `c20a9d1d0ee04daf6e9723767b1b9d1a8007445d` |

  Each disc is its own compile of the game, so the build recompiles the one you give it. Features and achievements are
  ported to each. The new discs were tested on the headless Linux test setup (first boot, menus, an arcade race), not
  yet on Windows, so reports from them are especially welcome.
- **A new settings window (F1):** a section list and full-width rows with a help footer, made to work with a controller.

## Also in this release

- Faster texture handling on Direct3D 12, from the other ports.
- The launcher's builds work on drives that record no file owners (exFAT, FAT32).

Known: the Japanese and Asian discs are not supported yet; the game's sound effects (reverb, filters) are not modelled;
system link and split screen have not been tested.
Please report problems on the [Discord server](https://discord.gg/PQjkKsdtc), with `PGR1\play\logs\pgr1.log` (the
game) or `PGR1\launcher.log` (building).
